# EastMesh print master

## File

- `eastmesh-logo-4096.png` — 4096 × 4096 px, RGBA PNG, 300 PPI metadata.

## Print guidance

- At 300 PPI: approximately 13.65 × 13.65 inches / 346.7 × 346.7 mm.
- At 200 PPI: approximately 20.48 × 20.48 inches / 520.2 × 520.2 mm.
- At 150 PPI: approximately 27.31 × 27.31 inches / 693.7 × 693.7 mm.

This is a faithful 4× Lanczos upscale of the original 1024 × 1024 EastMesh logo. It preserves the original composition and artwork but does not recreate detail that was absent from the source. For very large-format signage, embroidery, cut vinyl, or a printer requiring vector/CMYK artwork, commission or create a separate vector redraw and proof it against the original.
